# ملفات النشر الجاهزة — أداة تقييم أداء الشركة

هذا المجلد يحتوي النسخة المبنية الجاهزة للنشر مباشرة على GitHub Pages.

## طريقة النشر (3 خطوات)

1. افتح مستودعك على GitHub وفعّل GitHub Pages من: Settings → Pages → Source: **Deploy from a branch** → الفرع **gh-pages** → `/ (root)` → Save.
2. من تبويب Code في المستودع: Add file → Upload files، وارفع كل الملفات الموجودة هنا (index.html + مجلد assets + 404.html).
3. استنى دقيقتين وافتح: https://هazemmousa852-dot.github.io/Company-Evaluation/

ملاحظة: لا ترفع هذه الملفات في فرع main، ارفعها في فرع gh-pages فقط.
